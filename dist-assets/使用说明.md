# DSH 预设管理器 · 使用说明

这是一个给 **DeepSeek Harness（DSH）桌面端**用的插件：让你在会话中途切换 Agent 预设、按预设控制工具与引导、管理子代理能用的预设，并导入导出预设包。

压缩包里还自带一个预设 **「标准模式·加强版」**，装好插件就会自动出现在预设列表里，不需要另外导入。

---

## 一、最简单的安装方法（推荐）

1. **先把 DeepSeek Harness 完全退出**（托盘图标右键 → 退出；任务栏关掉窗口不算退出）。
2. 把本压缩包**解压**到一个你以后不会删的位置（比如 `D:\DSH插件\dsh-preset-manager`）。
   > 别在压缩软件里直接双击安装，要先解压。
3. 双击 **`安装(双击这里).cmd`**，看到 `[OK] Installed` 就成了。
4. 重新打开 DeepSeek Harness。
5. 看会话标题栏右侧，应该出现 **「预设 标准模式·加强版」**；打开 **设置 → 预设管理** 能看到配置页。

安装脚本会自动找到你的 DSH 和它的 profile 目录，把插件装进去，并备份被修改的文件。

## 二、用 DSH 界面安装（不想跑脚本时）

1. 解压压缩包。
2. 打开 DSH → **插件** → **安装第三方插件**。
3. 在输入框里填 **`package` 文件夹的完整路径**，例如：

   ```
   D:\DSH插件\dsh-preset-manager\package
   ```

   也可以填压缩包里那个 `.tgz` 文件的完整路径。
4. 点安装，然后重启 DSH。

> 注意：用这种方式装时，`package` 文件夹（或 `.tgz` 文件）**不能删、不能移动**，否则插件会失效。如果你希望装完就能删掉解压目录，请用第一种方法。

## 三、安装后怎么用

- **切换预设**：点标题栏右侧的「预设 + 当前名字」，选一个即可。对话历史会保留，**下一轮请求起生效**。
- **配置**：设置 → **预设管理**
  - 总开关：关掉后所有预设都不挂载预设管理工具（逐预设设置会保留）。
  - 每个预设有两列开关：`工具/引导`（是否给这个预设挂工具、注入提示词）、`子代理可用`（是否允许子代理用这个预设）。
  - 子代理预设：默认「与父代理相同」；关掉后可以为子代理指定默认预设。
  - 预设包：可以把某个预设导出成 JSON 分享给别人，也可以导入别人的 JSON。
- **斜杠命令**：`/preset` 列出预设，`/preset <id>` 直接切换。

## 四、卸载

双击 **`卸载.cmd`**，然后重启 DSH 即可。

也可以手动：设置 → 插件，把「预设管理器」移除；或在 profile 的 `package.json` 里删掉 `dsh-preset-manager`。

## 五、常见问题

**双击 cmd 一闪而过？**
多半是没找到 Node.js 也没找到 DSH。请确认 DSH 是正常安装的（不是绿色便携版），并且**至少启动过一次**。

**装完顶栏没变化？**
1. 确认是**完全退出**后重开的（不是关窗口）。
2. 打开 设置 → 插件 看看有没有「预设管理器」，有没有报错。
3. 之前装过旧版本的话，先跑一次 `卸载.cmd` 再重装。

**提示 `profile 缺少 package.json`？**
说明这个 profile 还没被 DSH 初始化过。先启动一次 DSH，再回来装。

**我装了别的插件市场，这里找不到？**
这个包是离线压缩包，不上架任何市场。想从市场装，用仓库里的索引源地址（见 GitHub 页面）。

## 六、安全提示

- 导入别人的预设包等于把对方的插件声明写进你的 profile 并挂载。**只导入可信来源**。
- 导入时会检查预设依赖的插件包是否已安装；缺失会拒绝并列出缺什么。但这个检查只判断「模块在不在」，不判断安全性。
